HALLOWEEN PARTY — frontend corregido

Sube index.html a tu hosting. Para mostrar el QR oficial de Yape/Plin, coloca la imagen oficial con nombre qr.png en la misma carpeta que index.html. Si qr.png no está presente, no se mostrará ningún recuadro de marcador de posición. La página es responsiva para móvil, tablet y escritorio.
El formulario solicita nombre y WhatsApp (correo opcional), calcula el total, permite elegir Yape/Plin o transferencia bancaria y abre WhatsApp con el pedido preparado. El comprador debe adjuntar su comprobante y pulsar Enviar.
